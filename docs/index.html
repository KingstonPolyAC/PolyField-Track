PolyField Track

A results viewing and display software package for FinishLynx and TimeTronics photo-finish systems.

Runs on Windows and Mac as a desktop device linked to your photo-finish results folder.

Download from polyfield.co.uk

Note — this manual is being updated for the latest version. The sections below reflect the core workflow; newer features (multiple overlays, the countdown widget, the Layout Builder, records and line view) are being added.

Overview

PolyField Track enables a web-based user interface for any device on the network to display results in multiple formats, and a self-service kiosk mode for athletes to search their own results.

It keeps the operator in control, only displaying once a result is saved to ensure positive validation of results prior to display. Multiple saves are supported, enabling early display of athletes in distance races, or display once the top 3 athletes have performances assigned.

Getting started

Set the results directory

First set the results directory — this is the folder FinishLynx or TimeTronics will save your results into (LIF, etc.). Click the red button in the top-right corner, “Select Results Folder”.

[ screenshot: Select Results Folder ]

Once set, the web user interface will build and access details will be displayed. You only need one instance of the software to be running; multiple displays are supported, with the maximum being determined by your network and the computer running the software.

You can change the results folder once set by re-visiting the top-right button “Change Folder”.

Staying in control

Whilst the desktop app can perform all functions, it is advisable to leave it on this screen and use a separate device or second screen connected to the web interface — leaving you in control of the Screensaver and Text display functions.

Text & screensaver

These enable you to display graphics or text messages on the connected displays, engaging your spectators. Sponsor graphics etc. can be shown this way.

You can cancel the graphics using the Clear button, or wait for the next Save to a result file — this will override the graphics and return to the result displays.

Text size

The default text size can be adjusted with the + and − buttons.

Rotation modes

The rotation mode determines how results with more than 8 competitors will display:

ModeBehaviour
ScrollTop 3 rows are locked; rows 4+ scroll through the remaining competitors.
PageResult paginates, showing 1–8 then 9–16 etc. on a rotation basis.
Scroll AllAll 8 rows scroll through the competitors with no locked positions.

Accessing the web views

The web views are best accessed through the web interface, using the access details provided at the top of the desktop app.

Multi-Result view

[ screenshot: Multi-Result view ]

The Multi-Result view displays results in a 2×2 or 3×2 matrix layout. They can be configured to show the latest results or rotate through all available results. The text size can be adapted, and a full-screen mode is available that hides the toolbar — any mouse movement will temporarily pop the toolbar up before hiding on inactivity again.

Results paginate, with the current page shown at the top for tracking. The search icon takes you to the self-service results kiosk.

Athlete kiosk (self-service)

The kiosk can also be accessed by directly browsing to <IP-ADDRESS>:3000/athlete.

By default the screen displays a search bar. An athlete can search for themselves by name or bib number, populating a drop-down list. Clicking on any name displays all performances of that athlete in the current results directory.

Clicking on any of these result cards displays that result full-screen for photo opportunities. Reset wipes the current search, and the back button in the top-left returns you to the search field.

Newer features Being expanded

These areas are part of the current release and full guidance is being written:

  • Displays & the Layout Builder — design custom scoreboard layouts from widgets and assign them per screen (via QR codes).
  • Overlays — text, screensaver, line view, clock, records and countdown, which can now be triggered in any combination.
  • Countdown overlay — count down to a target time of day with an editable caption.
  • Records & line view — celebratory record cards and photo-finish images on your displays.
  • Themes, bibs & club abbreviations, and choosing the network card on multi-adapter PCs.
